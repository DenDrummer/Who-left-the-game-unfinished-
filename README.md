# Who left the game unfinished?
This is a WIP game inspired by the old flash games "Upgrade Complete" 1 & 2, which can still be found and played on Armor Games. Inspiration from other games may be incorporated along the way.

In short, the core concept is that the game starts in a barebones state, and as you play you can upgrade the game from the shop, which is available between runs.

More info and some plans of what will be added can be found in the Obsidian vault (the `Who left the game unfinished` folder).

# On the use of AI
No generative AI, LLMs or results from either are welcome in this project.
This is a project made out the love of games and game development.
Besides the moral/ethical/ecological gripes, it also just takes away the fun and creativity in multiple ways.
