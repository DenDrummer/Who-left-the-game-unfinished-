## README
This is a WIP game inspired by the old flash games "Upgrade Complete" 1 & 2, which can still be found and played on Armor Games. Inspiration from other games may be incorporated along the way.

In short, the core concept is that the game starts in a barebones state, and as you play you can upgrade the game from the shop, which is available between runs.
